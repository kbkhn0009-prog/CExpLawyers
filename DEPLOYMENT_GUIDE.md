# Пошаговая инструкция: Развертывание сайта и подключение домена

## Вариант 1: Развертывание на Vercel (Рекомендуется)

Vercel - это платформа, специально созданная для Next.js приложений. Она обеспечивает автоматический деплой, CDN, SSL сертификаты и простую настройку доменов.

### Шаг 1: Подготовка проекта

1. Убедитесь, что проект готов к деплою:
   ```bash
   npm run build
   ```
   Если сборка проходит без ошибок, можно продолжать.

2. Убедитесь, что у вас есть файл `.env.local` с необходимыми переменными окружения (если требуется).

### Шаг 2: Создание аккаунта на Vercel

1. Перейдите на сайт [vercel.com](https://vercel.com)
2. Нажмите "Sign Up" (Регистрация)
3. Зарегистрируйтесь через GitHub, GitLab или Email
4. Подтвердите email (если регистрировались через email)

### Шаг 3: Подключение репозитория GitHub/GitLab

**Если ваш проект уже на GitHub/GitLab:**

1. Войдите в Vercel Dashboard
2. Нажмите "Add New..." → "Project"
3. Выберите ваш репозиторий с проектом
4. Нажмите "Import"

**Если проект еще не на GitHub:**

1. Создайте аккаунт на [github.com](https://github.com) (если еще нет)
2. Создайте новый репозиторий:
   - Нажмите "+" → "New repository"
   - Дайте название репозиторию (например, `consul-expert-lawyer`)
   - Выберите "Private" или "Public"
   - НЕ добавляйте README, .gitignore или лицензию (если они уже есть)
   - Нажмите "Create repository"

3. В локальной папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/consul-expert-lawyer.git
   git push -u origin main
   ```
   (Замените `ВАШ_ЛОГИН` на ваш GitHub логин)

4. Затем в Vercel Dashboard:
   - Нажмите "Add New..." → "Project"
   - Выберите только что созданный репозиторий
   - Нажмите "Import"

### Шаг 4: Настройка проекта в Vercel

1. **Framework Preset**: Должен автоматически определиться как "Next.js"
2. **Root Directory**: Оставьте пустым (если проект в корне репозитория)
3. **Build Command**: `npm run build` (должен быть по умолчанию)
4. **Output Directory**: `.next` (должен быть по умолчанию)
5. **Install Command**: `npm install` (должен быть по умолчанию)

6. **Environment Variables** (Переменные окружения):
   - Если у вас есть `.env.local`, добавьте все переменные вручную:
     - Нажмите "Environment Variables"
     - Добавьте каждую переменную (например, `OPENAI_API_KEY`, `SUPABASE_URL` и т.д.)
     - Выберите окружения: Production, Preview, Development
     - Нажмите "Save"

7. Нажмите **"Deploy"**

### Шаг 5: Ожидание деплоя

1. Vercel начнет процесс деплоя (обычно занимает 2-5 минут)
2. Вы увидите прогресс в реальном времени
3. После успешного деплоя вы получите временный URL вида: `https://consul-expert-lawyer-xxxxx.vercel.app`
4. **Проверьте сайт по этому URL** - он должен работать!

### Шаг 6: Подключение собственного домена

#### 6.1. Покупка домена (если еще нет)

Если у вас еще нет домена, купите его у одного из регистраторов:
- [Namecheap](https://www.namecheap.com)
- [GoDaddy](https://www.godaddy.com)
- [Reg.ru](https://www.reg.ru) (для российских доменов)
- [Timeweb](https://timeweb.com) (для российских доменов)

#### 6.2. Добавление домена в Vercel

1. В Vercel Dashboard откройте ваш проект
2. Перейдите на вкладку **"Settings"** → **"Domains"**
3. В поле введите ваш домен (например, `vash-domen.ru` или `www.vash-domen.ru`)
4. Нажмите **"Add"**

#### 6.3. Настройка DNS записей

Vercel покажет вам, какие DNS записи нужно добавить. Есть два варианта:

**Вариант A: Использование A-записей (для корневого домена)**

1. В панели управления вашего регистратора домена найдите раздел "DNS" или "Управление DNS"
2. Добавьте следующие записи:

   Для корневого домена (`vash-domen.ru`):
   ```
   Тип: A
   Имя: @ (или оставьте пустым)
   Значение: 76.76.21.21
   TTL: 3600 (или Auto)
   ```

   Для поддомена `www`:
   ```
   Тип: CNAME
   Имя: www
   Значение: cname.vercel-dns.com
   TTL: 3600 (или Auto)
   ```

**Вариант B: Использование CNAME (рекомендуется для поддоменов)**

Если вы хотите использовать только `www.vash-domen.ru`:
```
Тип: CNAME
Имя: www
Значение: cname.vercel-dns.com
TTL: 3600
```

**Вариант C: Использование DNS провайдера Vercel (самый простой)**

1. В Vercel при добавлении домена выберите опцию "Use Vercel DNS"
2. Vercel предоставит вам DNS серверы (например, `ns1.vercel-dns.com`)
3. В панели управления доменом измените NS (Name Servers) записи на предоставленные Vercel
4. Это может занять до 24 часов для распространения

#### 6.4. Ожидание распространения DNS

- DNS изменения могут занять от нескольких минут до 48 часов
- Обычно это занимает 1-4 часа
- Проверить статус можно в Vercel Dashboard → Settings → Domains
- Когда домен будет готов, появится зеленая галочка и статус "Valid Configuration"

#### 6.5. SSL сертификат

Vercel автоматически выдаст бесплатный SSL сертификат (Let's Encrypt) для вашего домена. Это произойдет автоматически после успешной настройки DNS.

### Шаг 7: Проверка работы сайта

1. Откройте браузер
2. Введите ваш домен в адресную строку (например, `https://vash-domen.ru`)
3. Сайт должен открыться!
4. Проверьте, что работает HTTPS (замочек в адресной строке)

## Вариант 2: Развертывание на другом хостинге

### Альтернативные платформы:

1. **Netlify** - похож на Vercel, также поддерживает Next.js
2. **Railway** - для более сложных приложений
3. **Render** - простой деплой с поддержкой Next.js
4. **VPS сервер** (DigitalOcean, Hetzner, Timeweb) - требует больше настроек

### Общий процесс для других платформы:

1. Зарегистрируйтесь на выбранной платформе
2. Подключите репозиторий GitHub/GitLab
3. Настройте переменные окружения
4. Запустите деплой
5. Добавьте домен в настройках платформы
6. Настройте DNS записи согласно инструкциям платформы

## Решение проблем

### Проблема: Домен не работает после настройки DNS

**Решение:**
1. Проверьте правильность DNS записей через [whatsmydns.net](https://www.whatsmydns.net)
2. Убедитесь, что прошло достаточно времени (до 48 часов)
3. Очистите DNS кэш: `ipconfig /flushdns` (Windows) или `sudo dscacheutil -flushcache` (Mac)

### Проблема: SSL сертификат не выдается

**Решение:**
1. Убедитесь, что DNS записи настроены правильно
2. Подождите еще несколько часов
3. В Vercel Dashboard проверьте статус домена

### Проблема: Сайт не обновляется после изменений

**Решение:**
1. Vercel автоматически деплоит при каждом push в репозиторий
2. Убедитесь, что вы сделали `git push`
3. Проверьте статус деплоя в Vercel Dashboard

### Проблема: Ошибки при сборке

**Решение:**
1. Проверьте логи сборки в Vercel Dashboard
2. Убедитесь, что все переменные окружения добавлены
3. Проверьте, что проект собирается локально: `npm run build`
